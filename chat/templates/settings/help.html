Frequently Asked Questions
💬 How to delete messages?
Tap and hold the message you want to delete. If you're the sender, you'll see options to delete it for yourself or for everyone.
🚫 How to block a contact?
Go to the user's profile and click the Block button. This prevents them from sending you messages.
⭐ How to star a message?
Tap the star icon next to any message to save it. Find all starred messages from the menu.
👥 How to create a group?
Click the Groups icon in the sidebar and select Create Group. Add members and set a group name.
